

## Bun ORM Integration

### Overview

The `db2dialect` package provides seamless integration between **Bun ORM** (v1.2.x+) and the **go_ibm_db DB2 driver**. This allows you to use Bun's modern ORM features with IBM DB2 databases while maintaining full DB2 SQL compatibility.

### Features

- **Native DB2 Pagination**: Automatic `OFFSET n ROWS FETCH NEXT m ROWS ONLY` generation
- **Go Type Mapping**: Automatic conversion of Go types to DB2 SQL types
- **DB2 Identity Support**: Auto-increment fields via `GENERATED BY DEFAULT AS IDENTITY`
- **Full Feature Support**: CTE, Common Table Expressions, SELECT EXISTS, Composite IN, and more

### Installation

1. **Install Bun ORM**:
   ```bash
   go get github.com/uptrace/bun@latest
   ```

2. **Use go_ibm_db driver** (already part of this repository):
   ```bash
   go get github.com/ibmdb/go_ibm_db@latest
   ```

### Quick Start Example

```go
package main

import (
	"database/sql"
	"fmt"
	"time"

	"github.com/ibmdb/go_ibm_db"
	"github.com/ibmdb/go_ibm_db/db2dialect"
	"github.com/uptrace/bun"
	"github.com/uptrace/bun/fixture"
)

// Define your model
type User struct {
	bun.BaseModel `bun:"table:users"`

	ID        int64     `bun:"id,pk,autoincrement"`
	Name      string    `bun:"name,type:varchar(255)"`
	Email     string    `bun:"email,type:varchar(255)"`
	Active    bool      `bun:"active,type:smallint"`
	CreatedAt time.Time `bun:",nullzero,default:current_timestamp"`
}

func main() {
	// 1. Open DB2 connection using go_ibm_db driver
	sqldb, err := sql.Open("go_ibm_db", "DATABASE=testdb;HOSTNAME=localhost;PORT=50000;UID=db2inst1;PWD=password")
	if err != nil {
		panic(err)
	}
	defer sqldb.Close()

	// 2. Wrap with Bun and use db2dialect
	db := bun.NewDB(sqldb, db2dialect.New())
	defer db.Close()

	// 3. Use Bun ORM normally
	ctx := context.Background()

	// Create table
	err = db.NewCreateTable().Model((*User)(nil)).Exec(ctx)
	if err != nil {
		panic(err)
	}

	// Insert
	user := &User{Name: "Alice", Email: "alice@example.com", Active: true}
	res, err := db.NewInsert().Model(user).Exec(ctx)
	if err != nil {
		panic(err)
	}
	fmt.Printf("Inserted user with ID: %d\n", user.ID)

	// Query with pagination (uses DB2's OFFSET...FETCH NEXT)
	var users []User
	err = db.NewSelect().
		Model(&users).
		Limit(10).
		Offset(0).
		Scan(ctx)
	if err != nil {
		panic(err)
	}

	fmt.Printf("Found %d users\n", len(users))
}
```

### Type Mappings

The db2dialect automatically maps Go types to DB2 SQL types:

| Go Type | DB2 SQL Type | Notes |
|---------|--------------|-------|
| `bool` | `SMALLINT` | 0 (false) or 1 (true) |
| `int`, `int8`, `int16`, `int32` | `INTEGER` | Standard 4-byte integer |
| `int64` | `BIGINT` | 8-byte integer for large IDs |
| `float32` | `REAL` | Single-precision floating-point |
| `float64` | `DOUBLE PRECISION` | Double-precision floating-point |
| `string` | `VARCHAR(255)` | Default length; use tags to customize |
| `[]byte` | `BLOB` | Binary Large Object |
| `time.Time` | `TIMESTAMP` | Date and time with microsecond precision |
| `*T` (pointer) | Dereferenced type | Nullable variant of base type |

### Pagination in DB2

Bun automatically generates the correct pagination SQL for DB2:

```go
// This Bun query:
var users []User
db.NewSelect().
  Model(&users).
  OrderBy("id").
  Limit(10).
  Offset(20).
  Scan(ctx)

// Generates this DB2 SQL:
// SELECT ... FROM users ORDER BY id OFFSET 20 ROWS FETCH NEXT 10 ROWS ONLY
```

### Model Tags

Use Bun tags to customize DB2 behavior:

```go
type User struct {
	ID      int64     `bun:"id,pk,autoincrement"`                    // Primary key with identity
	Name    string    `bun:"name,type:varchar(100)"`                 // Custom length
	Score   float64   `bun:"score,type:double"`                      // Explicit type
	Active  bool      `bun:"active,type:boolean,default:true"`       // DB2 BOOLEAN type
	Created time.Time `bun:",nullzero,default:current_timestamp"`    // DB2 default
}
```

### Supported Features

The db2dialect enables the following Bun features for DB2:

- ✅ **CommonTableExpressions (CTE)**: WITH clauses
- ✅ **WithValues**: Multiple row inserts with VALUES clause
- ✅ **SelectExists**: EXISTS subqueries
- ✅ **CompositeIn**: IN clauses with multiple columns
- ✅ **OffsetFetch**: DB2-native pagination (OFFSET...FETCH NEXT)

### Advanced: Manual Pagination Helper

For manual SQL building, use the `AppendOffsetLimit` helper:

```go
import "github.com/ibmdb/go_ibm_db/db2dialect"

// Build a paginated query manually
query := []byte("SELECT * FROM users ORDER BY id")
query = db2dialect.AppendOffsetLimit(query, 20, 10)
// query now contains: SELECT * FROM users ORDER BY id OFFSET 20 ROWS FETCH NEXT 10 ROWS ONLY
```

### Troubleshooting

#### "dialect.Name type mismatch"
This is expected during integration - ensure you're using Bun v1.2.x or later.

#### Pagination not working
Verify that `OffsetFetch` feature is enabled:
```go
d := db2dialect.New()
if d.Features().Has(feature.OffsetFetch) {
    fmt.Println("Pagination is enabled")
}
```

#### Type conversion issues
Check that model field types match the Go type mapping table above. Use explicit `bun:"type:..."` tags for custom mappings.
